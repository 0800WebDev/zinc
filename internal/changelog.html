V.3.6.0 – Proxy Update

2026

Changes:

  • Added zinc://preview page to preview any site in an iframe.
  • Added zinc://editor to edit any text file.
  • Added bookmark support.
  • Added a toolbar with bookmarks and extensions.
  • Added URL parameters: ?url= to set the URL, ?wisp= to set the Wisp server, and ?fullscreen=true to enable fullscreen.
  • Added view-source:https... along with a view source button to view html source code of any site.
  • Added a qr code generator that generates a qr with a proxied url of the current site.
  • Added an setting to change the tab cloak to whatever you want along with a variety of presets to choose between.
  • Added close protection with the abillity to change between automatic, enabled and disabled.
  • Added an setting to change the transport type between epoxy and libcurl.
  • Added an auto skip setting to automaticly skip loading when available.
  • Added an setting to paste in costum css to change the style of the site.
  • Changed extension upload to use zip files instead of folders.
  • Changed settings and wisp selection to be separate to make room for more servers..
  • Changed background uploads to be in the settings page.
  • Made it so that internal urls in the dropdown menu to open in a new tab instead of the current one.
  • Made it so that when the dropdown menu closes when you click a button or press outside of it.
  • Made zinc:// and extension:// urls show in the adress bar.
  • Fixed an issue where sites would open in a new browser tab instead of inside zinc.
  • Fixed an issue where the site would load forever instead of displaying errors on invalid urls.
  • Fixed removing and disabling extensions.

This is the biggest update so far so if you notice any issues, please report them on the official github repository
