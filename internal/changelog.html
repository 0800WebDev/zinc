Changelog

V.3.6.0 – Proxy Update

July 31, 2026

Changes:

  • Added zinc://preview page to preview any site in an iframe.
  • Added zinc://editor to edit any text file.
  • Added bookmark support.
  • Added a toolbar with bookmarks and extensions.
  • Changed internal urls in the dropdown menu to open in a new tab instead of the current one.
  • Added URL parameters: ?url= to set the URL, ?wisp= to set the Wisp server, and ?fullscreen=true to enable fullscreen.

If you notice any issues, please report them on the official github repository

July 18, 2026

Changes:
